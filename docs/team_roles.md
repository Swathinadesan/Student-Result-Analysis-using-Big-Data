# Team Roles

## Member 1 — HDFS / Data Storage
- Prepare and validate CSV dataset
- Create HDFS input directory
- Upload dataset to HDFS
- Explain distributed storage and HDFS commands

## Member 2 — MapReduce
- Explain Mapper and Reducer
- Run Hadoop Streaming MapReduce
- Explain key-value pairs, shuffle/sort and aggregation
- Verify processed output

## Member 3 — Hive Analytics
- Create Hive database/table
- Load/query student data
- Demonstrate topper, average and pass-percentage queries
- Explain Hive's SQL-based analytics layer

## Demo statement
The project uses HDFS for storage, Hadoop MapReduce for processing, and Apache Hive for analytics. Python is used for the Hadoop Streaming mapper and reducer.
