Student Result Analysis using Big Data is a mini-project that demonstrates how a student marks dataset can be stored, processed and analyzed using Big Data technologies. HDFS is used as the distributed storage layer, Hadoop MapReduce performs subject-wise aggregation, and Apache Hive provides SQL-based analytical queries. Python Hadoop Streaming programs implement the Mapper and Reducer. The system generates insights such as subject averages, highest marks, top students and overall pass percentage.
